This project is a technical evolution of the "360 No-Scope" 2-D shooter. By integrating Deep Reinforcement Learning (DRL), I am transforming a precision-based game into an autonomous training environment where an agent learns to master complex trick shots.

The goal is to move beyond hard-coded enemy behaviors and develop an AI capable of:

Spatial Intelligence: Navigating the arena using a custom-built radial sensor suite.


Precision Mechanics: Executing high-speed rotations and perfectly timed shots without human intervention.

Behavioral Optimization: Learning through a mathematical reward system that prioritizes "360-degree" style points alongside traditional survival.

Building on my B.S. in Computer Science and Minor in Mathematics , this project serves as a showcase for combining high-level software architecture with the practical application of Artificial Intelligence and Machine Learning algorithms
