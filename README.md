# 360 No Scope

**360 No Scope** is a dynamic 2D shooter game developed using the Godot Engine. This game challenges players to master precision and timing by performing impressive 360-degree no-scope shots. Designed for fast-paced action and skillful gameplay, *360 No Scope* offers an engaging experience that tests your reflexes in a unique and exciting way.

---

## Features

- **360-Degree Player Rotation:** Full range of motion allowing seamless aiming in all directions.  
- **No-Scope Shooting Mechanics:** Rewards precision and timing without relying on scope assists.  
- **Multiple Challenging Levels:** Progress through increasingly difficult stages that test your skills.  
- **Smooth and Responsive Controls:** Powered by the Godot Engine’s efficient architecture.

   ```bash

   cd 360-no-scope
Open the project in Godot Engine:

Launch the game directly through Godot's editor or export it to your preferred platform.

Gameplay Overview
Use keyboard, mouse, or gamepad controls to rotate your character 360 degrees freely.

Perform no-scope shots to eliminate targets and rack up points.

Advance through levels by completing objectives and improving your shooting skills.

Technology Stack
Game Engine: Godot Engine (latest stable release)

Scripting Language: GDScript
